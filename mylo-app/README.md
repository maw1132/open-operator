# Mylo AI Assistant

This directory contains the Expo based React Native application for Mylo.

## Setup

Install dependencies with `npm install` or `pnpm install` inside `mylo-app`.

### Environment Variables

Copy `.env.example` to `.env` and fill in:

```
OPENAI_API_KEY=your_openai_api_key
WEAVIATE_HOST=your_weaviate_endpoint
FITBIT_CLIENT_ID=your_fitbit_client_id
FITBIT_CLIENT_SECRET=your_fitbit_secret
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Running

```
pnpm start
```

This will start the Expo development server.
